Pi Drive
–
The robot always balances; drive commands only move what it balances around. With Pi Drive on, commands from the Pi (hailo-tracker's follower) drive it whenever the stick is centred or the transmitter is off — any stick input wins. No transmitter is needed. The gate only opens while armed and shuts on disarm or e-stop. Replaces the old Balance / Ext Ctrl picker: the UART input it selected was never used.
Drive
Lean — the stick sets a tilt angle, so it commands acceleration. Centring it means “stand up straight”, not “stop”, so you brake with reverse stick.
Target — the stick moves the hold point, so it commands speed. Release and the bot coasts to a halt by itself.
